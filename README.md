# ⚙️ Enginegame — ДВС симулятор
> Created by **ytakez**

Welcome! **Enginegame** is my personal web project — a minimalist, interactive simulator of an internal combustion engine (ДВС) and car transmission that runs right in your browser.

[🎮 Play the Game Live](ytakez.github.io/Enginegame)

---

## 🛠️ About the Project

I built this simulator to visualize how an engine responds to transmission shifts and pedal inputs. It’s a lightweight technical sandbox where you can experiment with gears, clutches, and RPM without leaving your browser.

## 🚀 Core Features

* **R4 Engine Simulation:** Watch a classic inline-four engine run and adapt in real time.
* **3D Mode & X-Ray View:** Switch to **3D** or hide the engine casing to closely inspect internal components and ignition phases.
* **Two Transmission Types:** Challenge yourself with a **6-speed Manual Gearbox** (R-1-2-3-4-5-6-N) or switch to a smooth **Automatic Transmission** (R-N-D).
* **Interactive Pedals:** Control the **Clutch**, **Brake**, and **Gas** pedals manually. Learn how to balance them to keep the engine from stalling!

## 💻 Tech Stack

This project is lightweight and uses no heavy frameworks:
* HTML5 / CSS3
* Vanilla JavaScript
* Hosted via **GitHub Pages**

## 🔧 How to Run Locally

If you want to look at the code or test it locally, just clone the repo and open the HTML file:

```bash
git clone https://github.com
cd Enginegame
# Simply open index.html in any modern web browser
```
